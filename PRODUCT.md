# Product

Native SwiftUI iOS client recreating Stremio's discovery and addon experience, based on the user's brief and local Windows 5.0.27 analysis. iPhone and iPad; existing deployment target iOS 26.0 retained for the installed Xcode SDK.

## Platform
ios

## Stack
Swift 6, SwiftUI, Foundation URLSession, Observation, AVKit. No third-party dependencies. Existing `MyMovie` application target and bundle identifier retained.

## Confirmed direction
Use the source-derived navy canvas and violet accent, poster-led catalogs, native tab navigation, and native playback controls. Live addon data supplies title artwork and metadata. The current implementation is a local guest client; it does not claim Windows playback parity or account synchronization.
